# Макет: лендинг НИИ нейронаук (без оболочки СамГМУ)

**Концепт:** отдельная посадочная страница института. Тот же контент, что у макета «СамГМУ Бизнесу», но **без** шапки, аудиторий, служебных ссылок и футера сайта samsmu.ru.

**Онлайн:** https://nsri-sam.github.io/site-mockup-landing-nii/

**Локально:** `index.html` · услуги: `usluga.html`

Рядом: [макет на samsmu.ru / Бизнесу](https://nsri-sam.github.io/site-mockup-samsmu-business/) · [вариант А](https://nsri-sam.github.io/site-mockup-a/) · [вариант Б](https://nsri-sam.github.io/site-mockup-b/)

## Что убрано относительно макета «СамГМУ Бизнесу»

- верхняя служебная полоса (оплата, RU/EN, сведения об ОО, слабовидящим)
- логотип и меню СамГМУ (образование, клиники, ЭИОС)
- вкладки аудиторий (университет / поступающим / … / бизнесу)
- футер СамГМУ (канцелярия, приёмная комиссия, госссылки, карта сайта)

## Что сохранено

| № | Блок |
|---|------|
| 1 | Hero + заявка / список услуг |
| 2 | Для кого |
| 3 | С какими задачами к нам приходят |
| 4 | Направления деятельности |
| 5 | Формат работы |

| 7 | Наша команда |
| 8 | Контакты + соцсети + модалка заявки |

Шапка лендинга — логотип НИИ и якорное меню по блокам. Футер короткий: институт, адрес, телефон, почта.
